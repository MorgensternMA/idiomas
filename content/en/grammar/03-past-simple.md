## Cuándo se usa

Para acciones **terminadas** en un momento del pasado que se dice o se sobreentiende:

- *I **saw** her yesterday.*
- *We **lived** in Córdoba for two years.* (ya no vivimos ahí)
- *When I was a kid, I **played** football every day.*

Equivale tanto a "comí" como, muchas veces, a "comía" (para hábitos también existe *used to*: *I used to play football*).

## Cómo se forma

**Regulares:** base + **-ed** → *work → worked, live → lived, stop → stopped, study → studied*.

**Irregulares:** hay que aprenderlos. Los más usados:

| Base | Pasado | | Base | Pasado |
|---|---|---|---|---|
| be | was / were | | get | got |
| have | had | | make | made |
| do | did | | take | took |
| go | went | | come | came |
| say | said | | see | saw |
| think | thought | | buy | bought |

**Negativa y pregunta:** con **did / didn't**, y el verbo vuelve a la base.

- *I **didn't go**.* — nunca *I didn't went.*
- ***Did** you **see** it?* — nunca *Did you saw it?*

*Be* es la excepción: *I wasn't there. Were you there?*

## Pronunciación del -ed

- /t/ después de sonidos sordos: *worked, stopped, watched*.
- /d/ después de sonidos sonoros: *lived, played, called*.
- /ɪd/ (sílaba extra) solo después de **t** o **d**: *wanted, needed*.

Error muy común: decir *work-ed* con dos sílabas. Es *workt*.
